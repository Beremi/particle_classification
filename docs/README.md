# Documentation

The root [README](../README.md) is the project overview. These pages are the
compact reference for the active data and modeling pipeline:

- [Raw data](raw-data.md) — local corpora, T3PA/CLOG formats, timing,
  calibration, provenance, and deterministic publishing archives.
- [Raw-data index](raw-data-index.md) — generated snapshot of the indexed T3PA
  working corpus.
- [DBSCAN](dbscan.md) — the active custom native Phase 1 separator, its build,
  parameters, command, and output schema.
- [Autoencoders](autoencoder.md) — the practical voxel z8 baseline and the
  pose-separated path research approach.

Detailed experiment reports, galleries, rejected variants, and older design
notes live in the [experimental archive](../experimental_notes/README.md).
Those notes preserve evidence, but their results may have been superseded by
later timestamp corrections, datasets, or model choices.

The archived [LaTeX report](../experimental_notes/background/particle_nn_report_updated/particle_nn_report.tex)
provides the original technical narrative. When it conflicts with the compact
pages above, prefer the current implementation and these core docs.
